# SPECIFICATION v1.0

## Vision
Créer un écosystème unique de génération de ressources pédagogiques.

## Principe
Une seule source (référentiel officiel) alimente toutes les productions.

## Pipeline
Programme → Référentiel → Progression → Chapitres Markdown → Générateur → PDF / HTML / Web.

## Chapitre type
1. Couverture
2. Objectifs
3. Automatismes
4. Je me souviens
5. Cours
6. Exemples détaillés
7. Critères de réussite
8. Synthèse
9. Auto-évaluation
10. Ressources numériques

## Ressources
- iParcours
- MathALÉA
- FlashMD
- CartesMD
- Kahoot
- Plickers
- Banque JS

## Versions générées
- Élève
- Professeur
- DYS
- HTML
- PDF

## Règle
> Une seule source. Plusieurs rendus. Zéro duplication.
