J'ai pré-rempli les compétences depuis ton tableau « Compétences par séquence » (le plus structuré). Quelques points où tes deux docs se contredisent ou où un code ne colle pas à sa description :
  • N1 : ton doc ALG note « Ch2 » mais avec la description de Ch1 (« extraire et reformuler »). J'ai mis Ch1 (le bon code).
  • Calcul littéral (N3, N6) : « calculer en langage algébrique » = Ca3, pas Ca2 (Ca2 = contrôler la vraisemblance). N3 est bon (Ca3) ; N6 est à passer en Ca3 si tu évalues la même chose.

  • N5 Fractions 1 : seule Co1 est cochée ; tu évalues sûrement aussi Ca1 (calcul).
