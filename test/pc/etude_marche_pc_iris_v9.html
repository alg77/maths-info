Config minimum à viser

CPU : Ryzen 5 5600 / i5-12400F minimum, idéal i5-14400F ou Ryzen 5 7600.
GPU : RTX 4060 minimum, RTX 5060 / 5060 Ti recommandé.
RAM : 16 Go suffisent, 32 Go plus tard.
SSD : 1 To NVMe.
Carte mère : éviter A520/H610 si possible ; viser B550/B650/B760/B860.
Alim : 650W de marque connue.
