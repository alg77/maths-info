⚙️ Configuration cible pour Iris

Minimum raisonnable

  • CPU : Ryzen 5 5500 / i5-12400F
  • GPU : RTX 5060
  • RAM : 16 Go, idéalement dual channel
  • SSD : 1 To
  • Carte mère : B550/B760 ou mieux
  • Alimentation : 500–650 W Bronze correcte

Idéal long terme

  • CPU : Ryzen 5 7500F
  • GPU : RTX 5060 Ti
  • RAM : 16 Go DDR5 aujourd’hui, 32 Go plus tard
  • SSD : 1 To minimum
  • Plateforme : AM5
  • Boîtier : micro-ATX compact avec vitre

🧾 Notes finales à garder

  • Le “F” du Ryzen 7500F signifie seulement qu’il n’a pas de partie graphique intégrée. Avec une RTX 5060 Ti, ce n’est pas un problème.
  • 512 Go de SSD est le seul vrai défaut du Little Dragon : passer à 1 To est l’upgrade le plus utile.
  • 16 Go de RAM suffisent aujourd’hui. Pour du montage vidéo plus régulier, viser 32 Go plus tard.
  • La plateforme AM5 du Little Dragon vieillira mieux que l’AM4 du Sprint.
  • Le Sprint reste un très bon achat si on veut préserver le budget écran + accessoires.
