# A1.03 | Score, bonus et objets à attraper | 4e | Ch2,Ch3,Re1

:::rappel | Objectif de la séance
Je crée un objet à attraper et une variable `score`.

Une variable contient une valeur qui peut changer pendant le jeu.
:::

## Créer une variable

:::def | Variable
Une variable est une mémoire du programme.

Dans un jeu, elle peut servir à retenir :

- le score ;
- le temps restant ;
- le nombre de vies ;
- le niveau atteint.
:::

:::methode | Initialiser le score
Au début du jeu :

1. Créer une variable `score`.
2. Quand le drapeau vert est cliqué, mettre `score` à [[$0$]].
3. Afficher le score sur la scène.
4. Tester que le score revient bien à 0 quand on relance.
:::

## Attraper un objet

:::methode | Bonus à récupérer
Pour le lutin bonus :

1. Le placer à une position aléatoire.
2. Répéter indéfiniment.
3. Si le bonus touche le joueur, alors ajouter 1 au score.
4. Replacer le bonus à une nouvelle position aléatoire.
:::

:::exemple | Effet attendu
Si le score vaut 4 et que le joueur attrape un bonus, le score devient [[$5$]].
:::

## Améliorer le jeu

:::methode | Variantes possibles
Choisir une seule amélioration :

- un bonus rare qui rapporte 5 points ;
- un son quand on attrape un objet ;
- un effet visuel ;
- un bonus qui disparaît et réapparaît ;
- plusieurs objets à attraper.
:::

:::reussite | J'ai réussi si...
- La variable score existe.
- Le score revient à 0 au début.
- Le score augmente quand le joueur touche un bonus.
- Le bonus change de place après avoir été attrapé.
:::
