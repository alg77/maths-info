# A1 | Algorithmique : fil rouge Scratch et Nuit du Code | 4e | Ch2,Ch3,Re1

:::rappel | Pourquoi ce fil rouge ?
L'objectif de l'année est de devenir capable de créer un petit jeu vidéo dans Scratch : comprendre un univers, imaginer une règle de jeu, coder, tester, améliorer et présenter son projet.

Ce parcours prépare progressivement à un défi de type « Nuit du Code » : les élèves découvrent un univers graphique, puis construisent un jeu jouable en temps limité.
:::

## Organisation proposée

:::methode | 6 séances en demi-groupe
1. Découvrir Scratch et piloter un personnage.
2. Construire un joueur : déplacements, coordonnées et limites.
3. Ajouter un score avec des objets à attraper.
4. Créer des obstacles, des vies et des conditions.
5. Structurer un vrai jeu : début, fin, difficulté, messages.
6. Réaliser un mini-défi Nuit du Code.
:::

:::reussite | Compétences travaillées
- Écrire un programme simple pour réaliser un objectif.
- Modifier un programme donné pour changer son comportement.
- Tester, corriger et améliorer un programme.
- Coopérer en binôme en séparant les rôles : idée, code, test, présentation.
:::

## Fiches séparées

:::methode | À utiliser au fil de l'année
Les fiches sont autonomes :

- `4A1-01` : premiers pas dans Scratch ;
- `4A1-02` : déplacer un joueur ;
- `4A1-03` : score et objets à attraper ;
- `4A1-04` : obstacles, vies et conditions ;
- `4A1-05` : organiser un vrai jeu ;
- `4A1-06` : mini-défi Nuit du Code.
:::

:::rem | Pour la progression
Cette séquence peut rester affichée comme un seul chapitre A1 dans la progression, mais les séances peuvent être distribuées séparément pendant l'année, par exemple après un chapitre de géométrie, de repérage ou de calcul littéral.
:::
