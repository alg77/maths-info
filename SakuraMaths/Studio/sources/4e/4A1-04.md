# A1.04 | Obstacles, vies et conditions | 4e | Ch2,Ch3,Re1

:::rappel | Objectif de la séance
Je programme un obstacle et une variable `vies`.

Je comprends le rôle d'une condition : « si... alors... ».
:::

## Ajouter des vies

:::methode | Variable vies
Au début du jeu :

1. Créer une variable `vies`.
2. Mettre `vies` à [[$3$]].
3. Afficher les vies sur la scène.
4. Vérifier qu'elles reviennent à 3 quand on relance.
:::

## Programmer une collision dangereuse

:::def | Condition
Une condition permet d'exécuter une action seulement si un test est vrai.

Exemple : si le joueur touche l'obstacle, alors il perd une vie.
:::

:::methode | Obstacle
Pour le lutin obstacle :

1. Le placer dans la scène.
2. Le faire bouger lentement.
3. Répéter indéfiniment.
4. Si l'obstacle touche le joueur, alors enlever 1 à `vies`.
5. Replacer le joueur au départ.
6. Attendre un court instant pour éviter de perdre toutes les vies d'un coup.
:::

:::exemple | Calcul des vies
Si le joueur a 3 vies et touche un obstacle, il lui reste [[$2$]] vies.
:::

## Fin de partie

:::methode | Quand les vies arrivent à 0
1. Répéter indéfiniment pendant le jeu.
2. Si `vies = 0`, afficher « Perdu ! ».
3. Arrêter les scripts du jeu.
4. Tester en touchant volontairement l'obstacle.
:::

:::reussite | J'ai réussi si...
- Le joueur perd exactement une vie après une collision.
- Le joueur revient au départ.
- Le jeu s'arrête quand les vies valent 0.
- Je sais expliquer le test utilisé dans la condition.
:::
