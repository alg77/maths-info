# A1.05 | Organiser un vrai jeu : début, fin et difficulté | 4e | Ch2,Ch3,Re1

:::rappel | Objectif de la séance
Je transforme une collection de scripts en vrai jeu avec :

- un début clair ;
- une règle compréhensible ;
- une condition de victoire ;
- une condition de défaite.
:::

## Préparer le début du jeu

:::methode | Initialisation
Quand le drapeau vert est cliqué :

1. Placer le joueur au départ.
2. Mettre le score à 0.
3. Mettre les vies à 3.
4. Afficher les bons lutins.
5. Cacher les messages de fin.
6. Expliquer la règle en une phrase.
:::

:::exemple | Règle courte
« Attrape 10 cristaux avant de perdre tes 3 vies. »

La victoire arrive quand le score vaut [[$10$]].
La défaite arrive quand les vies valent [[$0$]].
:::

## Gérer la victoire

:::methode | Condition de victoire
1. Répéter indéfiniment.
2. Si `score = objectif`, afficher « Gagné ! ».
3. Jouer un son ou changer de décor.
4. Arrêter le jeu.
5. Tester avec un objectif plus petit, par exemple 2 points.
:::

## Ajouter de la difficulté

:::methode | Une amélioration à choisir
Choisir une amélioration raisonnable :

- les obstacles accélèrent ;
- le temps est limité ;
- les bonus changent plus vite de place ;
- un deuxième niveau apparaît ;
- un objet piège enlève des points.
:::

:::rem | Important
Un bon jeu n'est pas forcément compliqué.

Un bon jeu est compréhensible, testable et améliorable.
:::

:::reussite | J'ai réussi si...
- Le jeu commence toujours dans le même état.
- La règle est écrite clairement.
- Le joueur peut gagner.
- Le joueur peut perdre.
- J'ai testé au moins une victoire et une défaite.
:::
