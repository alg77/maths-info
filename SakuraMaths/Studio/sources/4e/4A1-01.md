# A1.01 | Scratch : premiers pas et univers de jeu | 4e | Ch2,Ch3,Re1

:::rappel | Objectif de la séance
Je découvre l'interface de Scratch et je comprends qu'un jeu est composé :

- de [[lutins]] ;
- d'une [[scène]] ;
- de [[scripts]] ;
- d'évènements qui déclenchent des actions.
:::

## Se repérer dans Scratch

:::methode | Les 4 zones à connaître
1. La scène : c'est l'écran du jeu.
2. Les lutins : ce sont les personnages et les objets.
3. Les blocs : ce sont les instructions.
4. La zone de script : c'est l'endroit où l'on assemble les blocs.
:::

:::exemple | Premier script
Quand on clique sur le drapeau vert :

- le lutin se place au centre ;
- il dit bonjour ;
- il avance.

Dans Scratch, le bloc qui lance souvent le programme est [[quand drapeau vert est cliqué]].
:::

## Comprendre un univers de jeu

:::methode | Observer avant de coder
Avant de coder, je prends 5 minutes pour observer l'univers proposé :

1. Quels sont les personnages possibles ?
2. Quels objets peuvent devenir des bonus ?
3. Quels objets peuvent devenir des obstacles ?
4. Quel décor peut devenir un niveau ?
5. Quelle histoire très simple peut tenir en une phrase ?
:::

:::exemple | Une idée de jeu en une phrase
« Le panda doit récupérer des bambous avant la fin du temps, sans toucher les lanternes rouges. »

Le joueur contrôle [[le panda]].
Le bonus est [[le bambou]].
L'obstacle est [[la lanterne rouge]].
:::

## Mini-défi

:::methode | À faire en binôme
1. Choisir un lutin joueur.
2. Choisir un décor.
3. Faire dire au joueur le titre du jeu.
4. Faire bouger le joueur de 20 pas quand on appuie sur une touche.
5. Tester le programme.
6. Changer une chose et retester.
:::

:::reussite | J'ai réussi si...
- Je sais lancer un programme avec le drapeau vert.
- Je sais ajouter au moins un lutin.
- Je sais déplacer un lutin avec une touche.
- Je sais expliquer le rôle d'au moins deux blocs.
:::
