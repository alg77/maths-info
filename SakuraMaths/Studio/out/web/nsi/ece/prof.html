 Éditeur

def normalisation_tel(num):
    clean_num = ''
    for c in num:
        if c.isdigit():
            clean_num += c
    return clean_num

def plus_proche_possible(self, nom_smoothie_ref):
    max_communs = 0
    smoothie_proche = None
    for nom_smoothie in self.db_smoothies:
        if nom_smoothie != nom_smoothie_ref and self.smoothie_possible(nom_smoothie):
            nb_communs = self.score_proximite(nom_smoothie_ref, nom_smoothie)

def alerte_valeur_aberrante(empreinte, limite):
    valeur_aberrante = False
    for categorie, valeur in empreinte.items():
        if est_dictionnaire(valeur):
            valeur_aberrante = valeur_aberrante or alerte_valeur_aberrante(valeur, limite)

            if valeur > limite:
                valeur_aberrante = True
    return valeur_aberrante

 Éditeur
Explication : L'essentiel à faire ressortir : le nombre de pucerons mangés dépend du ratio proies/coccinelle (trois paliers), et le niveau de nutrition monte ou redescend selon ce qui a été consommé.
def chasser(self, nb_proies, nb_coccinelles):
    """Renvoie le nombre de pucerons restants après la chasse du jour,
    et met à jour le niveau de nutrition de la coccinelle."""
    if nb_coccinelles == 0:
        return nb_proies                      # personne pour chasser
    proies_par_cocci = nb_proies / nb_coccinelles
    if proies_par_cocci > 20:
        consomme = random.randint(12, 20)     # proies abondantes
    elif proies_par_cocci > 10:
        consomme = random.randint(8, 15)
    else:
        consomme = random.randint(3, 8)       # proies rares
    consomme = min(consomme, nb_proies)
    if consomme >= 10:
        self.niv_nutrition += 1
    else:
        self.niv_nutrition = max(0, self.niv_nutrition - 1)
    return nb_proies - consomme

Q1 Q2 Q3 Q4
Une image en niveaux de gris est vue comme une liste de valeurs (0 à 255, une par pixel). Sur des dessins/schémas avec de grands aplats de couleur uniforme, on peut la compresser en remplaçant chaque suite de valeurs identiques (un « run ») par un couple (nombre de répétitions, valeur) : c'est le codage RLE (run-length encoding). Exemple : [4,4,4,0,5,5] devient [3,4, 1,0, 2,5].

📄 Code / éléments fournis

exemple — codage fourni (à ne pas modifier au départ)
def codage_rle(liste_octets):
    """Renvoie une liste d'octets obtenue par compression RLE (version initiale,
    incomplète : ne gère pas les répétitions de plus de 255)."""
    liste_rle = []
    i = 0
    while i < len(liste_octets):
        c = liste_octets[i]
        k = 1
        while i+k < len(liste_octets) and liste_octets[i+k] == c:
            k += 1
        liste_rle.append(k)
        liste_rle.append(c)
        i += k
    return liste_rle

Q1 : Répondre — Expliquer / observer

Q1
La liste obtenue par codage RLE est-elle forcément de longueur inférieure ou égale à la liste de départ ? Justifier avec un exemple.
 Éditeur
Explication : Non : sur une liste sans répétitions, chaque valeur devient un couple (compte, valeur), donc la taille double. Exemple : [3, 5, 0, 6] (longueur 4) donne [1,3, 1,5, 1,0, 1,6] (longueur 8), deux fois plus longue.

Q2 : Écrire — Écrire

Q2
En étudiant codage_rle (fournie), écrire le corps de decodage_rle(liste_rle) qui reconstitue la liste d'octets d'origine. Des tests sont fournis dans test_codage(), à compléter si besoin.
 Éditeur
Explication : On relit la liste RLE deux valeurs par deux valeurs (compte, valeur), et on répète chaque valeur compte fois.
def decodage_rle(liste_rle):
    """Renvoie la liste d'octets obtenue a partir de liste_rle
    (compressee par codage RLE)."""
    lst = []
    for i in range(0, len(liste_rle), 2):
        for k in range(liste_rle[i]):
            lst.append(liste_rle[i+1])
    return lst

def test_codage():
    assert codage_rle([255, 255, 0, 255, 255, 255]) == [2, 255, 1, 0, 3, 255]
    assert decodage_rle([2, 255, 1, 0, 3, 255]) == [255, 255, 0, 255, 255, 255]
    assert decodage_rle([4, 85]) == [85, 85, 85, 85]
    print("Tests codage/decodage : OK")

Q4
Le problème vient d'un dépassement : sur une grande image, une même valeur peut se répéter plus de 255 fois d'affilée, ce qu'un octet ne peut pas coder. Proposer une solution et l'implémenter dans codage_rle (et decodage_rle si nécessaire).
 Éditeur
Explication : Il suffit de découper les longues répétitions en plusieurs « paquets » de 255 au maximum, chacun suivi de la valeur répétée.
def codage_rle(liste_octets):
    """Renvoie une liste d'octets obtenue par compression RLE,
    en decoupant les series de plus de 255 repetitions."""
    liste_rle = []
    i = 0
    while i < len(liste_octets):
        c = liste_octets[i]
        k = 1
        while i+k < len(liste_octets) and liste_octets[i+k] == c and k < 255:
            k += 1
        liste_rle.append(k)
        liste_rle.append(c)
        i += k
    return liste_rle
