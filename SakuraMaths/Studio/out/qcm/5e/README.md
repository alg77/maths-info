# QCM et automatismes 5e

Ces fichiers sont générés par `python builders/build_5e_practice.py`.

- `qcm-5e.html` : QCM autocorrectif à partir des générateurs d'automatismes.
- `automatismes-flash-5e.html` : version flash libre issue de la progression.
- `mini-eval-automatismes-5e.html` : mini-évaluations spiralaires 20 questions, sujets + corrigés.
- `practice-5e-data.js` : objectifs, automatismes et chapitres normalisés.
- `automatismes-5e-generators.js` : générateurs aléatoires utilisés par le QCM.
