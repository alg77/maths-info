# QCM et automatismes 4e

Ces fichiers sont générés par `python builders/build_4e_practice.py`.

- `qcm-4e.html` : QCM autocorrectif à partir des automatismes du pont-livret.
- `automatismes-flash-4e.html` : pioche flash de début de séance.
- `mini-eval-automatismes-4e.html` : mini-évaluations spiralaires 20 questions, sujets + corrigés.
- `practice-4e-data.js` : objectifs, automatismes et chapitres normalisés.
- `automatismes-4e-generators.js` : générateurs aléatoires et relances flash.
