🌸 Mémo — qui va où & quoi redéployer

Deux univers séparés. Une fois que c'est clair, plus d'emmêlage.

① Les deux univers

🌐 Le site

GitHub Pages

Des fichiers .html, .css, .js, images.

Tous dans le même dossier de ton dépôt GitHub.

Public, partageable par URL.

Mise à jour = téléverser les fichiers modifiés sur GitHub.

📓 Le Carnet

Google Apps Script

Deux fichiers : Index.html + Code.gs.

On les colle dans l'éditeur Apps Script (script lié à ton Google Sheet). Ce n'est pas dans GitHub.

Privé.

Mise à jour = coller + Déployer → nouvelle version.

Piège classique : le Index.html du Carnet (majuscule, chez Google) n'a rien à voir avec le index.html du site (minuscule, sur GitHub). Deux fichiers différents, deux endroits.

③ Qui va où

FichierDestination
Toutes les pages du site (.html, site.js, .css, images)Dossier GitHub
couverture-5e.html, referentiel-5e.htmlDossier GitHub (à côté des progressions)
Index.html + Code.gs (le Carnet)Apps Script
pont-carnet-5e.jsonFichier de passage — téléchargé puis téléversé

④ Quoi redéployer, quand

Si tu modifies…Tu redéploies…
Une page du site, le menu, le CSSGitHub — téléverse le(s) fichier(s) modifié(s)
Le menu (site.js)GitHub — un seul fichier, il s'applique à toutes les pages
La page CouvertureGitHub — couverture-5e.html seul
Le Carnet (Index.html ou Code.gs)Apps Script — colle + Déployer → nouvelle version
Tes objectifs / associations (page Couverture)Rien à déployer — c'est mémorisé dans le navigateur ; pour le carnet, ré-exporte le JSON

⑤ Le pont entre les deux (le JSON)

  1. Sur le site, j'associe mes objectifs dans couverture-5e.html.
  2. Je clique ⬇️ Pont carnet → ça télécharge pont-carnet-5e.json.
  3. Dans le Carnet, bouton 📚 Programme → Importer ce JSON → je choisis le fichier.
  4. Pour mettre à jour plus tard : je ré-exporte et je réimporte — le même niveau est remplacé.

⑥ Bon à savoir

🔹 Aperçu « nu » : dans l'éditeur ou un aperçu isolé, une page s'affiche sans le CSS/JS voisins. C'est normal — il faut la voir déployée (sur GitHub, ou via le Carnet déployé).

🔹 Carnet : l'onglet Referentiel se crée tout seul au 1ᵉʳ import (sinon, lancer migrate() une fois).

🔹 Couverture : la 1ʳᵉ fois sur un appareil, ouvre ta progression 5ᵉ une fois (elle s'enregistre seule) pour que les chapitres apparaissent.
