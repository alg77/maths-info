À adapter pour la rentrée 🌿

Progression pré-remplie depuis le BO Première NSI. Référentiel = les 6 compétences LSL, thèmes = les grands domaines du programme.
  • Ordre proposé : types de base → programmation → types construits → bibliothèques/Pyxel (lancement du fil rouge) → algorithmique → données en tables → Web → architecture/systèmes/réseaux → finalisation du jeu & Nuit du Code, avec l'histoire de l'informatique en fil rouge. Tu n'avais pas de doc perso, donc c'est un point de départ à t'approprier.
  • Théorie et pratique mêlées dans chaque séance (salle info disponible sur tout l'horaire) : plus de split jour dédié, une seule zone d'objectifs par séquence.
  • Projet fil rouge Pyxel : lancé en P2 juste après les types construits (tableaux/dictionnaires nécessaires pour gérer les entités du jeu), réinvesti explicitement en L1 (algorithmique → collisions, score, IA simple), finalisé en P3 juste avant la Nuit du Code.
  • Logique des prérequis : les types construits (tableaux, dictionnaires) précèdent Pyxel, l'algorithmique et le traitement de données en tables, qui en dépendent.
  • Durées estimées (4 h/sem, ~30,5 sem. avec le projet Pyxel) volontairement prudentes : il te reste de la marge pour les évals — ajuste librement.
  • Fin d'année calée sur le réel : cours jusqu'au 1ᵉʳ vendredi de juin (4 juin 2027 ici), avec les ECE de NSI la semaine précédente (1ʳᵉ semaine de juin, laissée volontairement libre de toute séquence). Avec ce calendrier, P3 (finalisation Pyxel + présentation) tombe naturellement sur mi → fin mai, la fenêtre habituelle de la Nuit du Code — cale la date exacte de présentation dans cet intervalle une fois connue.
